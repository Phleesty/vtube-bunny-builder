# vtube unuasha — bunny animator & sequence builder 🐰

Интерактивный веб-конструктор слоёв и покадровый симулятор анимаций зайки для оверлея стримера **unuasha** (`vtube-unuasha-hud`).

Позволяет собирать кастомного персонажа из независимых слоёв художника, симулировать походку с реальным перемещением по экрану, настраивать связку «походка $\to$ падение» (`Walk → Fall`) на нативной частоте **8 FPS**, и в один клик экспортировать готовый ID, JSON или прямую ссылку.

---

## ✨ Возможности

1. **Покадровая сборка слоёв в реальном времени (HTML5 Canvas):**
   * **Основа тела:** в фартуке (`fartuk`) / без фартука (`nude`).
   * **Головной убор:** без шапочки / поварской колпак (`hat1`) / берет (`hat2`).
   * **Аксессуары:** без аксессуаров / бантик на ушко (`bowl`).
   * **В лапках:** пустые лапки / кусочек торта (`cake`) / стаканчик кофе (`coffee`) / чашка (`cup`).
2. **Физика перемещения и сценарии:**
   * **`Walk → Fall`:** зайка шагает по экрану заданное количество шагов, после чего спотыкается и падает на месте с паузой перед повтором.
   * **`Walk (Движение)`:** непрерывный проход через весь экран слева направо с зацикливанием.
   * **`Walk (На месте)` / `Fall (На месте)`:** центрированный статичный предпросмотр для детального осмотра слоёв.
3. **Нативный тайминг 8 FPS:**
   * Игровой цикл на `requestAnimationFrame` со строгим интервалом 125 мс на кадр (и возможностью изменения ползунком).
   * Регулировка скорости шага (пикселей сдвига за кадр).
   * Пошаговая перемотка (Step) и пауза (Пробел).
4. **Мгновенный экспорт и шеринг:**
   * **Компактный ID:** например, `walk_fall:fartuk:hat1:bowl:cake:8fps:spd14`.
   * **JSON-конфиг:** для прямого копирования в параметры виджета алерта.
   * **Прямая URL-ссылка:** все параметры записываются в строку запроса (Query Params) в реальном времени. Можно просто скинуть ссылку стримеру или разработчику!
5. **Тестирование контраста:**
   * Переключение фонов сцены (шахматная сетка прозрачности, тёмный, доска кафе, хромакей).
